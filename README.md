# Commute-photo

현장 출퇴근 근거(출력일보 서명지 · 19:00 안전모 사진)를 엑셀 출퇴근표로 옮기는 작업.

| 폴더 | 내용 |
|---|---|
| [`출력일보/`](출력일보/) | 출력일보 → `출입기록 기반 출퇴근표` 채우기 스크립트(`fill_ot.py`), 작업 방식 · 고치는 법 · 한계(README), 날짜별 기록 CSV |
| [`기성/`](기성/) | 같은 일일 기록으로 월 기성 공수 · 금액 계산(`gisung.py`), 원본 기성 엑셀 점검 항목 · 한계(README) |
| [`사진 글자 추출/`](사진%20글자%20추출/) | 안전모 사진에서 읽은 이름 · 시간 표 |

양식 · 결과 xlsx(생년월일 등 개인정보), 기성 설정(계약 금액 · 단가)은 올리지 않는다 — 각 폴더 `.gitignore`.
