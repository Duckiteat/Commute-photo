# 기성 집계 (사진 기록판)

월 기성(하도급 기성 내역서 · 검사원 · 신청서)의 **공수와 금액**을, 게이트 출입기록 대신
**사진으로 받은 일일 기록**으로 계산한다.

```
원래:  출입기록(게이트) → 분류 테이블(출퇴근 시간 → 코드) → 일일·근무자별 → 월간 근무표 → 기성 내역서 → 검사원 → 신청서
지금:  사진(출력일보 서명지 · 19:00 안전모) → 기록/날짜.csv → gisung.py → 기성 내역 · 월간 집계 · 근무자별 · 일일 · 점검
```

일일 기록은 [`../출력일보/기록/`](../출력일보/기록/)과 **같은 CSV**를 쓴다. 하루 한 번 만들면 출퇴근표 채우기와 기성 집계에 함께 쓰인다.

## 한 달 작업 순서

1. **설정 뽑기** (회차 시작 때 한 번): 지난달 기성 파일에서 계약 공수, 단가, 전회 누계, 인원(식별표), 공휴일, 가중치를 뽑는다.
   ```
   python3 gisung.py 설정 <지난 기성.xlsb> -o 설정.json --다음회차
   ```
   그다음 `설정.json`에서 아래를 손으로 고친다.
   - `기간`을 채운다.
   - 지난 회차 확정 금액을 `이전회차금액` 끝에 더한다.
   - 새로 들어오거나 나간 사람을 `인원`에 반영한다(`투입시작`, `투입끝`).
   - 새 공휴일을 `공휴일`에 더한다.
2. **매일**: 출력일보 사진을 받으면 Claude가 `../출력일보/기록/YYYY-MM-DD.csv`를 만든다(출력일보 README 참고).
3. **기성 때**:
   ```
   python3 gisung.py 계산 설정.json ../출력일보/기록 -o 기성_10회.xlsx
   ```
   결과 시트는 다음과 같다.
   - `기성 내역`: 직종별 계약, 전회, 금회, 누계, 기성율, 잔여. 초과한 줄은 빨간색이다. 아래에 금회 공급가액과 VAT가 있다.
   - `월간 집계`: 직종 × 평일/주말 × 조출·주간·연장·야간·철야.
   - `근무자별`: 사람 × 날짜 공수표. 주말·공휴일 날짜 머리는 빨간색, 주간이 아닌 날은 노란색이다.
   - `일일 근무표`: 기록 한 줄당 한 줄과 근거.
   - `점검`: 중요 / 확인 / 알림.
4. **원래 기성 파일에 옮기기**: `기성 내역`의 금회 공수를 원래 엑셀 '3.하도급 기성 내역서' 금회 칸에 옮기거나 대조한다. 나머지 시트(검사원, 신청서)는 원래 파일의 수식이 따라온다.

## 구분과 공수

기록 CSV의 `구분` 칸 하나로 그날 공수가 정해진다. 원래 엑셀 식별표의 코드표와 같은 값이다.

| 구분 | 평일 | 주말·공휴일 | 원래 코드 |
|---|---|---|---|
| 주간 | 1 | 1.5 | 135 / 235 |
| 연장 | 1.5 | 2.25 | 136 / 236 |
| 야간 | 2 | 3 | 137 / 237 |
| 조출 | 1.5 | 2.25 | 165 / 265 |
| 조출+연장 | 2 | 3 | 166 / 266 |
| 조출+야간 | 2.5 | 3.75 | 167 / 267 |
| 철야 | 2 | 3 | 철야 |
| 오전 · 오후 | 0.5 | 0.75 | 134 · 145 / 234 · 245 |
| 연차 · 결근 · 휴무 · 미출근 | 0 | 0 | — |

가중치(조출 0.5, 주간 1, 연장 0.5, 야간 1, 철야 2, 주말은 1.5배)는 `설정.json`의 `가중치`에서 바꾼다.

## 검증

10월(9회) 원래 파일의 출입기록을 일일 기록으로 바꿔(`gisung.py 출입기록`) 계산했다. 원래 엑셀과 **사람별 공수, 직종별 공수, 금회 금액, 누계 기성율이 모두 같았다**. 단 하나 다른 곳은 원래 엑셀에서 연장 수식이 지워진 3칸이며, 원본 점검 항목 4에서 설명한다.

## 점검이 잡는 것

- **중요**: 계약 공수 초과(누계 > 계약), 모르는 구분, 계약에 없는 직종, 이전 회차 금액 합 ≠ 직종별 전회 금액 합.
- **확인**: 명단에 없는 이름(공수에서 빠짐), 같은 날 중복, 투입 기간 밖 기록, 기록 파일이 없는 평일, 기성율 90% 이상, 전회 공수 × 단가 ≠ 전회 금액.
- **알림**: 한 글자 차이 이름 교정, 주말·공휴일 근무.

## 원본 기성 엑셀에서 볼 곳 (9회 파일 점검에서 나온 것)

1. **신청서 비고의 회차별 금액**: 빈 회차가 있으면 신청서 누계가 내역서와 검사원 누계보다 작게 나온다.
2. **신청일자**: 신청서와 검사원 두 곳에 있다. 지난 회차 날짜가 남아 있지 않은지 본다.
3. **회사명**: 신청서 위쪽과 아래쪽(협력업체용)이 같은지 본다.
4. **분류 테이블의 연장(U) 열**: 수식이 지워진 칸이 있으면 그 사람의 연장이 0이 된다. 일부러 뺀 것이면 특이사항에 이유를 적는다.
5. **월간 근무표의 주말 칸 합계 범위**: 평일 칸과 같은 행부터 시작하는지 본다. 다르면 앞쪽 사람들의 주말 공수가 빠진다.
6. **월간 근무표의 Leader 칸 수**: 칸이 2줄뿐이면 Leader가 3명일 때 빠진다.
7. **내역서와 월간 근무표의 `#REF!` 칸**.

## 한계

1. **시간이 없다**: 사진 기록에는 출퇴근 시각이 없다. 그래서 원래 엑셀의 '출근·퇴근 시간대 → 코드' 판정을 하지 않고, 출력일보의 서명 칸(구분)을 그대로 믿는다. 지각, '8시간 준수', 19:20 이전 퇴근 같은 시간 기준 판단은 사람이 구분을 정할 때 해야 한다.
2. **연장 기준이 다를 수 있다**: 원래 엑셀은 퇴근 타각이 19:20 이후일 때만 연장으로 쳤다. 사진 방식은 연장 칸 서명(+ 19:00 사진)으로 연장을 인정한다. 원청이 어느 기준으로 인정하는지 확인이 필요하다.
3. **인원 명단에 없는 사람은 금액에서 빠진다**: 직종을 모르기 때문이다. `점검` 시트에 '확인'으로 뜨니 `설정.json`의 `인원`에 더한다.
4. **검사원과 신청서는 만들지 않는다**: 금액 계산까지만 하고, 원래 엑셀 서식에 옮기는 건 사람이 한다.
5. **철야 날짜 넘김**: 철야(밤 → 다음 날 새벽)는 기록 파일의 날짜 하루에 몰아 센다.
6. **공휴일**: `설정.json`의 목록만 안다. 대체휴일, 선거일 등 새 공휴일은 직접 더해야 한다.

## 파일

- `gisung.py`: 명령은 `설정`, `계산`, `출입기록`이다. 필요한 것은 Python 3.9+, `openpyxl`, xlsb를 읽을 때 `pyxlsb`(`pip install pyxlsb`)이다.
- `설정.예시.json`: 설정 모양을 보여 주는 예시이며 값은 가짜다.
- `설정.json`, `*.xlsx`, `*.xlsb`는 계약 금액, 단가, 개인정보가 있어 **저장소에 올리지 않는다**(`.gitignore`).
